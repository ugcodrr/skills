# Morning sheet

What an unattended run leaves for the owner: one offline HTML page, `index.html` in the run folder.

- Matched before and after at display size, native crops, full coverage, criterion vectors, changed regions and sizes.
- Gate evidence, the registered baseline violations, the missing checks, and the unchanged negative controls.
- Options as A/B, each with one concrete trade-off, saying whether it changes information, behavior or an owner call.

Each pair says which region to look at and which side is today. An idea comes with a rendered attempt or a marked crop, since it can't be judged from today's picture alone. The owner approves before anything is merged, folded or pushed.
